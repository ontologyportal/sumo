# Source and generated problems

ARI is TFF only; BIO, TIM, TRN, MED, GEG, GEO, PUZ, NUM, and CSR may have FOF, TFF, and THF formulations. BIO groups problems by biological topic and declares per-problem KIF sources. TIM covers temporal reasoning across geochronology, causation, duration units, communication, medicine, astronomy, weather, government, and walking. TRN covers transportation services, vehicles, transit infrastructure, shipping, and parking. MED covers medical processes, devices, conditions, and measurements. Each source test names the KIF files needed for its conjecture. Source topics can differ from TPTP export domains; MED aligns with the existing TPTP Medicine domain, while TRN has no assigned TPTP export domain yet.

Source files use stable SUMO IDs with a form/version suffix, such as `kif/ARI/SMO_ARI_0001_1.kif.tq`. Generated problems use `DDDNNNFV[.SSS].p` when assigned a TPTP number (`-` CNF, `+` FOF, `_` TFF, `^` THF). Included axiom files use the `.ax` extension.

Free variables in source queries are implicitly universally quantified; write explicit exists only for existential witnesses. Source tests declare their KIF background with include metadata. GEG tests select tests/CASC/axiom-sets/full.sources, which mirrors the repository full-SUMO constituent list. The TQ runners and exporter still need to resolve includes before these tests can be executed or translated; see INCLUDE-PLAN.md.
