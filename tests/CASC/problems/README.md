# Source and generated problems

ARI is TFF only; AST, BIO, TIM, TRN, MED, FIN, WEA, FOD, GEG, GEO, PUZ, NUM, and CSR may have FOF, TFF, and THF formulations. AST covers astronomy and space: celestial bodies, planetary systems, stellar processes, satellites, and space transportation. Its problems may combine Astronomy.kif with Mid-level-ontology.kif, Transportation.kif, and engineering concepts. BIO groups problems by biological topic and declares per-problem KIF sources. TIM covers temporal reasoning across geochronology, causation, duration units, communication, medicine, astronomy, weather, government, and walking. TRN covers transportation services, vehicles, transit infrastructure, shipping, and parking. MED covers medical processes, devices, conditions, and measurements. FIN covers account ownership, banking transactions, fees, balances, and interest. WEA covers wind, precipitation, cloud cover, pressure, visibility, and severe weather. FOD covers food classification, preparation, preservation, meals, and composition. Each source test names the KIF files needed for its conjecture. Source topics can differ from TPTP export domains; MED aligns with the existing TPTP Medicine domain, while AST, TRN, FIN, WEA, and FOD have no assigned TPTP export domains yet.

Source files use stable SUMO IDs with a form/version suffix, such as `kif/ARI/SMO_ARI_0001_1.kif.tq`. Generated problems use `DDDNNNFV[.SSS].p` when assigned a TPTP number (`-` CNF, `+` FOF, `_` TFF, `^` THF). Included axiom files use the `.ax` extension.

Free variables in source queries are implicitly universally quantified; write explicit exists only for existential witnesses. Source tests declare their KIF background with include metadata. GEG tests select tests/CASC/axiom-sets/full.sources, which mirrors the repository full-SUMO constituent list. The TQ runners and exporter still need to resolve includes before these tests can be executed or translated; see INCLUDE-PLAN.md.
