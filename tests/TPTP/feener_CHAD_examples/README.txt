Thesis Work 

"CHAD: Computational Handling of Axiomatic Deontics"

The examples in this folder are for the 3 modalities
of deontic logic, their combinations, and paradoxes 

Automated tests have been revised and added 
to include all example categories 1-9 

To run automated script:

  Make sure to have Vampire installed and 
  in path environment variable 

  Go to AUTO_VAMPIRE directory 

  Run python on auto_vampire.py to see help msg 
  and run with desired option
